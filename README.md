# Простой A/B-тест: старая vs новая версия сайта
Представим, что у интернет-магазина есть две версии сайта:
- **A** — старая версия
- **B** — новая версия (например, с другой кнопкой оформления заказа)

Для каждого пользователя знаем только одно: купил он что-то или нет.
Нужно понять, у какой версии доля купивших (конверсия) выше.

## Файлы

| Файл | Что делает |
|---|---|
| `generate_data.py` | Создаёт тестовые данные (`data.csv`): 1000 пользователей в группе A, 1000 в группе B |
| `analysis.py` | Считает конверсию по каждой группе, сравнивает и строит график |
| `data.csv` | Данные (создаются при запуске `generate_data.py`) |
| `result.png` | График сравнения (создаётся при запуске `analysis.py`) |

## Как запустить

```bash
python generate_data.py
python analysis.py
```

## Пример результата

```
Группа A: 95 из 1000 купили (9.5%)
Группа B: 133 из 1000 купили (13.3%)

Разница между B и A: 3.8 процентных пункта
Вывод: у группы B (новая версия) конверсия выше.
```
